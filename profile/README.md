<p>本文讲三件事：住宅IP的纯净度到底指什么，有哪些能自己动手的检测步骤，以及怎样把结果折算成可横向比较的分数。顺序是先拆指标、再逐项查、最后打分，买前验货和买后复检都适用。</p>
<h2>一、纯净度不是玄学，先拆成四个可测维度</h2>
<p>行业里说纯净，通常混着四件事：地址注册信息是否真实、历史上有没有被滥用、网络特征与所在地是否自洽、实际链路质量是否达标。四件事互不替代，一项漂亮不代表整体可用。</p>
<p>拆开的好处是能落地。不必相信服务商的形容词，只要给每一项找可复现的查法，把原始数据记下来，换供应商时就能横向对比。</p>
<h2>二、第一层：查 ASN 与地址注册信息</h2>
<h3>whois 与 IP 情报站怎么配合看</h3>
<p>先查 ASN 编号和持有者名称。住宅宽带的 ASN 一般对应本地运营商，比如各州的 cable 或光纤接入商；如果 ASN 落在机房托管号段里，这条线本质还是数据中心出口。</p>
<p>再看地址段的用途标注和注册时间。号段很新、或整段登记为托管用途，都要打问号。查完截图存档，隔一周复测一次。</p>

<h2>三、第二层：查历史滥用记录</h2>
<h3>黑名单命中该怎么看</h3>
<p>多数情报站会给滥用评分、黑名单命中和最近一次被投诉时间。分数不是判决书，但一个地址在多个库里同时标红，基本可以判断它被反复用于批量注册或抓取。</p>
<p>不要只看一个库。垃圾邮件名单、代理检测库、风控厂商评级各查一遍。命中集中在代理与托管类，说明这段地址被识别过的概率不低。</p>
<h2>四、第三层：看 DNS、时区与指纹是否自洽</h2>
<p>把设备时区、系统语言、DNS 解析服务器所在地对齐到你声称的位置，再打开 WebRTC 测试页看真实出口有没有泄漏。三者互相打架，比 IP 本身更早暴露问题。</p>
<p>DNS 最容易被忽略。解析请求若从另一块大陆发出，即使页面显示你在洛杉矶，服务端也能从解析路径看出异常。检查方法是访问 DNS 泄漏测试页，比对解析服务器与出口的 ASN。</p>
<h2>五、第四层：实测延迟、丢包与带宽</h2>
<p>从实际办公网络 ping 网关和几个公共 DNS，连续跑两百个包看丢包与抖动。住宅宽带的正常表现是延迟稳定、抖动小，晚高峰略升，但不会出现规律性掉线。</p>
<h3>测速怎么才准</h3>
<p>带宽要分开测上下行。很多家宽线路下行够用、上行只有十几兆，做直播或大量上传时立刻露馅。测速用同一台机器、同一时段，测三次取中间值。</p>

<h2>六、把四项合成一张评分表</h2>
<p>给四个维度分权重：注册信息三成、历史记录三成、网络特征两成、链路质量两成。每项按查到的结果打一到五分，加权得到总分，不同供应商的 IP 才具备可比性。</p>
<p>分数只是筛选工具，最终仍要回到业务。同一批地址在网页访问上表现正常，换到长连接或视频可能完全不同，所以打分后要拿真实业务跑一轮。</p>

<h2>常见问答</h2>
<h3>住宅IP纯净度有官方统一标准吗？</h3>
<p>答：没有。各家情报站口径不同，评分只能作参考。靠谱做法是固定几项硬指标，每次按同一流程查，看趋势而不是看单次分数。</p>
<h3>新买的IP一查就有滥用记录，还能用吗？</h3>
<p>答：要看命中类型。命中垃圾邮件库且时间久远，影响通常有限；同时在多个代理检测库被标记，说明这段地址被大量用于同类用途，建议换段。</p>
<h3>检测要装什么软件吗？</h3>
<p>答：大部分项目用网页工具就够：whois 查询、IP 情报站、黑名单批量查询、DNS 泄漏测试、测速页。只有连续 ping 和路由追踪需要命令行，系统自带即可。</p>
<h3>多久复检一次比较合理？</h3>
<p>答：首次使用前完整查一遍，之后每月抽查一次。IP 的历史记录会随时间变化，长期租用的地址若突然被大量投诉，表现会在几天内明显变差。</p>
